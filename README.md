
مشروع HumaScale: منصة التقييم الذكي لجاهزية الفرق غير الربحية (نظام كامل Full-Stack)
نظرة عامة على النظام
هذا المشروع عبارة عن نظام متكامل (Full-Stack) من تصميم وتنفيذ الطالب، يهدف إلى تقديم منصة رقمية تساعد المنظمات غير الربحية والفرق التطوعية على تقييم جاهزيتها التشغيلية وتحليل نقاط القوة والضعف لديها. يتكون النظام من واجهة أمامية تفاعلية (Frontend) مبنية على React، وواجهة خلفية (Backend) مبنية على Laravel Sanctum لإدارة المصادقة والبيانات بشكل آمن.

1. البنية التحتية للواجهة الأمامية (Frontend Architecture)
تم بناء الواجهة الأمامية باستخدام React 18 و Vite كأداة بناء، مما وفر بيئة تطوير سريعة وأحجام حزمة صغيرة (حجم البناء الكلي يبلغ 797 كيلوبايت فقط). تم اعتماد React Router v6 لإدارة التنقل بين الصفحات، وTailwindCSS لتطبيق نظام تصميم مخصص ومرن يدعم الاتجاه من اليمين إلى اليسار (RTL) باستخدام خط Cairo ليتناسب تماماً مع البيئة العربية.

أدوات التواصل مع الخادم:
تم استخدام مكتبة Axios مع أنظمة اعتراض (Interceptors) مخصصة لإدارة رؤوس المصادقة (Tokens) بشكل منفصل تماماً للمستخدمين العاديين ومسؤولي النظام (Admins)، مما يضمن أماناً أعلى للبيانات.

2. هيكلية ووظائف المستخدم العادي (User Features)
تم تصميم نظام متكامل للمستخدمين العاديين ليتيح لهم تجربة تقييم سلسة ومفصلة:

نظام المصادقة والوصول: يشمل النظام صفحة هبوط (Landing Page) احترافية، إلى جانب كامل دورة المصادقة (تسجيل الدخول، إنشاء حساب جديد، استعادة كلمة المرور، وإعادة تعيينها)، مع حماية المسارات الداخلية بواسطة (Protected Routes) لمنع الوصول غير المصرح به.

صفحة التقييم الرئيسية (Assessment Core): تم تطوير آلية تقييم تفاعلية تتيح للمستخدم الإجابة على 18 سؤالاً موزعة بدقة على 6 محاور استراتيجية. تم تزويد الواجهة بشريط تقدم (Progress Bar)، ونقاط تنقل بين الأسئلة، مع خاصية حفظ الإجابات بشكل لحظي (Auto-save) لمنع فقدان التقدم.

لوحة التحكم والنتائج (Dashboard & Results): تعرض لوحة التحكم ملخصاً سريعاً عن حالة المنظمة. أما صفحة النتائج فتمثل نقلة نوعية في عرض البيانات، حيث تم دمج مكتبة Recharts لعرض مخططات رادار (Radar Charts) ومخططات شريطية (Bar Charts) تحلل النتائج عبر المحاور الستة.

الأدوات الإضافية: شمل النظام صفحة لعرض سجل التقييمات السابقة مع إمكانية الوصول لنتائجها، وملف شخصي للمستخدم، ونظام إشعارات ديناميكي يتيح للمستخدم وضع علامة "قراءة" على الإشعارات. كما تم تضمين خاصية تحميل تقرير PDF لنتائج التقييم.

3. لوحة تحكم الإدارة (Admin Dashboard)
تم إنشاء واجهة منفصلة تماماً لمدير النظام (Admin) يتم الدخول إليها عبر بوابة مخصصة، وتحتوي على أدوات متقدمة للإشراف على النظام:

إدارة المستخدمين: عرض قائمة كاملة بالمستخدمين المسجلين مع خاصية البحث (Search) وتقسيم الصفحات (Pagination) لسهولة التصفح.

إدارة التقييمات: توفر لوحة التحكم للمدير رؤية شاملة لجميع التقييمات المقدمة في النظام، مع إمكانية استخدام فلاتر بحث متعددة (مثل: مستوى الجاهزية، التواريخ، والترتيب حسب الأقدمية).

تفاصيل التقييم: يمكن للمدير فتح أي تقييم مفصل ومراجعة إجابات المستخدم ونتائجه بشكل كامل.

التحليلات المتقدمة: تحتوي لوحة الأدمن على قسم خاص للتحليلات (Analytics) يعرض رسومًا بيانية توضح أداء المحاور المختلفة على مستوى المنصة بأكملها.

4. الإحصاءات الفنية للمشروع
إجمالي ملفات الواجهة الأمامية (Frontend): 49 ملف (JSX / JS).

إجمالي سطور الكود: 5,470 سطر.

حجم الحزمة النهائية (Build Size): 797 كيلوبايت إجمالاً (216 كيلوبايت مضغوط للـ JavaScript، و 6.3 كيلوبايت مضغوط للـ CSS).

حالة البناء: npm run build تم تنفيذها بنجاح وبدون أي أخطاء في الترتيب (Dependencies).
